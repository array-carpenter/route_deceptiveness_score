# Steps for Running this Notebook

1. Ensure you have downloaded the data from Kaggle (Placed in .gitignore for me due to large file size). Place all data in a folder called "data/raw"
2. Run data_cleaning.py, which will create the "combined" folder for the transformed data.
3. Run the train_model notebook, which will create the "models" subfolder in the data folder.
4. Run the build_metric notebook.
5. (Optional) Run the visualizations notebook to generate some plots. I treated this as my notebook for all plot creations.
